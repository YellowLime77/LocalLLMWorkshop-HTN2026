# Local LLMs Workshop - Hack the North 2026

*Led by moi*

A learning experience, a tool to help you write your Devpost submission, and something to implement into your project, all in one. How lucky! :)

## Structure

Inside this repo are two folders:

1. **DevpostWriter** - an incomplete app that, when completed, can help you write your Devpost description. Follow along to finish building the app, then learn how to switch from a cloud LLM API to Ollama's local LLM API to run the app fully on your own device.
2. **Takeaways** - code files that implements LLM calls, falling back to the local Ollama API when the cloud provider fails. Available in Python, JS, and TS for you to add quickly and easily to your own project. <ins>Remember to set your .env vars</ins>!
